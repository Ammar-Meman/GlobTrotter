# GlobeTrotter Frontend

This is the frontend application for GlobeTrotter, built with React, Vite, Tailwind CSS, shadcn/ui, React Router, Zustand, React Hook Form, and Zod.

## Setup Instructions

1. Ensure you have Node.js installed.
2. Clone the repository and navigate to the `frontend` folder:
   ```bash
   cd frontend
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Configure environment variables (a default `.env` is provided with `VITE_API_URL` and `VITE_USE_MOCK_APIS=true`).
5. Start the development server:
   ```bash
   npm run dev
   ```

## Workflow

Follow the branch strategy defined in the main `GlobeTrotter_Detailed_Timeline.md`. Do not commit directly to `main`.
